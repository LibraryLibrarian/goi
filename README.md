# goi

日本語入力システム（IME）向けの、コミュニティで育てるオープン辞書。

標準の辞書では変換できない新語、企業名、製品名、作品名、人名、IT用語などを集め、各 IME 向けの辞書ファイルとして配布することを目指す。辞書データは GitHub 上で管理し、Pull Request で追加・修正する。

現在の対象は Android 版 Gboard（単語リストのインポート機能）。

> 開発初期段階（Phase 1: MVP）。

## Gboardで使うときの注意

- 辞書を更新して取り込み直しても、以前に取り込んだ語は端末の単語リストに残ります。辞書で修正・削除された語は、Gboardの単語リストから手動で削除してください
- Gboardの単語リストには、語をまとめて削除する機能がありません。Gboardのアプリのデータを消去すると単語リストも消えますが、テーマなどほかの設定も初期化されます
