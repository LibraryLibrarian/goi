# Gboard インポート挙動の検証（2026-11-21）

Gboard 18.6.3（Android）の単語リストのインポート挙動を、専用エミュレーター上で検証したときのスクリプト。製品コードではなく、検証の記録として残している。

## 環境

- AVD: `goi_gboard_api33`（android-33 google_apis arm64、root 可）
- プリインストール版の Gboard を削除し、実機から取り出した Gboard 18.6.3 を入れた
- 起動: `emulator -avd goi_gboard_api33 -port 5580 -writable-system`、続けて `adb -s emulator-5580 root`
- スナップショット `base`: 日本語キーボードを追加し、単語リストが空の状態

## スクリプト

| ファイル | 用途 |
|---|---|
| `gen.py` | 検証用の ZIP を生成する（`python3 gen.py <出力先>`） |
| `ui.py` | uiautomator で画面要素を表示・タップする補助スクリプト |
| `imp.py` | 単語リスト画面から ZIP をインポートし、DB の件数を表示する |
| `timed.sh` | 大量インポートの所要時間を計測する |
| `conv.sh` | ローマ字を入力して変換候補の画面を保存する |
| `mozcount.py` | Gboard 内部の Mozc ユーザー辞書（protobuf）の件数を数える |

パスは検証時の `/tmp/goi-spike` を前提にしている。

## 主な結果

- 形式は v2。ヘッダーは `# Gboard Dictionary version:2` と `# Gboard Dictionary format:shortcut\tword\tlanguage_tag\tpos_tag` の2行。改行は LF、BOM なし
- 品詞は日本語名（品詞なし／名詞／固有名詞／人名／姓／名／組織／地名 など。Mozc の品詞体系と同じ）
- 読み・表記・品詞が完全に一致する語は、再インポートしても重複しない
- 表記を変えた語を取り込むと、古い語も残る。品詞だけを変えた語を取り込むと、単語リストの行が増える
- 不正な行があると、その行で取り込みが止まる（エラーは表示されない）
- BOM 付き、またはヘッダーなしの場合は列がずれる。品詞名が不正な場合は、単語リストには表示されるが変換候補に出ない
- 表記は100文字（300バイト）までは変換に出る。101文字は出なかった
- 50,000件は約5〜6分で取り込めた。最後の一部は、Gboard を再起動するまで変換に反映されない
